O Camisa10 é um projeto de e-commerce desenvolvido para o curso técnico de **Desenvolvimento de Sistemas do SENAI**. O site é especializado na venda de camisas de times nacionais e estrangeiros, focando na experiência de produtos importados.

## 🎯 Critérios Atendidos (Requisitos do Projeto)

Este projeto foi construído seguindo rigorosamente os critérios técnicos solicitados:

* **🎲 Uso de APIs:** Integração de dados dinâmicos para funcionalidades essenciais.
* **💰 Conversão de Moeda (USD para BRL):** Como os produtos são importados, o sistema consome uma API de cotação para converter os valores de dólares para reais em tempo real.
* **🚚 Cálculo de Frete:** Integração com API de logística para calcular o valor do envio baseado na região do cliente.
* **📱 Responsividade:** Design totalmente adaptável para dispositivos móveis, tablets e desktops.
* **2️⃣ Multi-telas:** O projeto conta com o mínimo de 2 telas (Home/Listagem e Detalhes do Produto/Carrinho).

## 🛠️ Tecnologias e Recursos

* **Linguagens:** HTML5, CSS3 e JavaScript.
* **APIs Utilizadas:** AwesomeApi e ViaCEP
